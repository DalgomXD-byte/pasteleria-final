PASTELERÍA DULCE MANTARO — TIENDA EN LÍNEA
==========================================

CÓMO ABRIRLO
Abre index.html con doble clic, o en VS Code con "Open with Live Server".
No usa librerías ni frameworks: HTML, una hoja de estilos (CSS) y JavaScript.
Antes de presentar, entra a index.html y haz clic en
"Restablecer datos de ejemplo" (al pie de la página).

CÓMO FUNCIONA
Todas las pantallas comparten los mismos datos: productos, pedidos, usuarios
y categorías. Se guardan en localStorage (la memoria del navegador), así que
lo que haces en una pantalla se ve en las demás. En el sistema real, ese
papel lo cumple el backend con la base de datos (Spring Boot + MySQL).
Los precios YA INCLUYEN IGV: el total es la suma de los importes.

INGRESO
Los logins (cliente y personal) dejan entrar con cualquier correo y
contraseña: comprobar las credenciales es trabajo del backend
(Spring Security + BCrypt).

RECORRIDO PARA LA DEMO
1. Cliente   : Catálogo -> agrega productos -> Carrito (cambia cantidades,
               usa la papelera, el total cambia al instante) -> Confirmar.
               El stock baja y el pedido aparece en Mis pedidos (RECIBIDO).
2. Cajero    : Bandeja -> Atender el pedido nuevo -> EN PREPARACIÓN o LISTO.
               La bandeja muestra el estado nuevo y el botón "Atendido".
3. Cajero    : Delivery -> asigna un repartidor (queda ASIGNADO).
4. Repartidor: Mis entregas -> Ver -> EN CAMINO -> ENTREGADO.
5. Cliente   : Mis pedidos muestra la línea de tiempo completa con las horas.
6. Cajero    : Venta en mostrador -> cantidades -> Efectivo -> Registrar.
               Total y vuelto en tiempo real; el ticket muestra la venta.
7. Admin     : cambia un precio o inactiva un producto: el catálogo del
               cliente cambia al instante. Desactiva un repartidor: ya no aparece en Delivery.

CÓMO SE HACE CADA COSA (preguntas típicas)
- Pasar de una página a otra: enlaces <a href> y location.href en JavaScript.
- Guardar datos entre páginas: localStorage.setItem / getItem con JSON
  (funciones cargar() y guardar() de datos.js).
- Dibujar tablas y tarjetas: cada pantalla tiene un contenedor vacío
  (<tbody id="filas">) y una función mostrar...() que lo llena con innerHTML.
- Calcular en tiempo real: el evento oninput llama a la función que suma.
- Estados que solo avanzan (RN-20): la lista muestra todos; el actual va con
  "selected disabled" y los que no se pueden elegir con "disabled".
- Editar en la fila: cada campo lleva form="editar-CODIGO", que lo une al
  formulario (y al botón Guardar) de esa misma fila.
- Validaciones simples: atributos de HTML5 (required, min, max, pattern).
  Las reglas del negocio (stock, código único, correo único) en JavaScript.
- Contraseñas: el campo no tiene "name", así nunca aparece en la dirección.
